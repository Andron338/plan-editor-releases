# Plan Editor releases

The released builds of Plan Editor for macOS and Windows. The apps check here for updates and install them by
themselves; the source code is kept elsewhere.

Download the newest version from [Releases](../../releases/latest):

- **macOS:** `PlanEditor-<version>-macos.zip` (Plan Editor.app). The first time, open it with right-click ▸ Open.
- **Windows:** `PlanEditor-<version>-windows.zip` (the exe with the printer scripts), or `PlanEditor.exe` on its own.
- **Both:** `PlanEditor-<version>-all.zip`.

`latest.json` in each release says which version is newest, for the apps' update check.
